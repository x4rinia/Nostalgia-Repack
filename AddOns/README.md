# Installing the AddOns

Copy each AddOn folder in this directory to your own Vanilla 1.12.1 client's `Interface\AddOns` directory:

- `DinoController` — controller UI, camera/cursor handling, mappings, HUD, and `/dino`
- `DinoMacroManager` — controller-oriented macro chain management
- `xbot` — PartyBot/BattleBot interface
- `SellGrey` — gray-item vendor helper
- `Clock` — lightweight in-game clock

Do not copy this README and do not nest the outer `AddOns` directory inside the client's AddOns directory. SavedVariables are intentionally not included.
