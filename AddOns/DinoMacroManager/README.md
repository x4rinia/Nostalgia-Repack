# DinoMacroManager

Spell-chain manager for World of Warcraft 1.12.1. Open it with `/dmm`.

- Provides 14 character-specific slots with two to four steps each.
- Accepts player spells from the spellbook plus the fixed `Pet: Attack` and `Bot: Attack` actions.
- Each chain has an optional timer reset, target-change reset and skip-unavailable-step behavior.
- Use **Save** before dragging a chain onto a standard Blizzard action bar.
- Left-click a slot to trigger its current step; right-click it to edit.
- Key bindings are available under `Key Bindings > DinoMacroManager`.

The AddOn keeps its SavedVariables in the user's own client; no personal settings are shipped here.
