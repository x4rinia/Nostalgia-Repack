# DinoControllerBridge

The included bridge is the current working 1.0.0.0 build used by this repack. Start it with the launcher's **Start Controller Bridge** button or run `DinoControllerBridge.exe` directly.

The bridge reads `DinoControllerBridge.json` from this directory. It uses portable relative placement and contains no game-client path. Connect an XInput-compatible controller first. The default mappings send the keyboard keys expected by DinoController; edit the JSON only while the bridge is stopped.
