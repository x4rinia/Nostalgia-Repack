# DinoController 1.0.0

Eigenstaendiges Controller- und HUD-Addon fuer **WoW Vanilla 1.12.1**.

- Addon-Ordner nach `Interface/AddOns/DinoController/` kopieren.
- Mit `/dino` das Menue oeffnen.
- Fuer XInput-Controller unter Windows die separat mitgelieferte
  `DinoControllerBridge.exe` im WoW-Hauptordner starten.

DinoMacroManager ist optional. Seine Actionbar-Makros lassen sich ueber die
vom DinoController bedienten ActionSlots ausloesen.
